How it works (30 seconds)
  1. Every team and agent has a playbook: how much to read, which rules to follow, when to say "I don't know". Every version is saved in MongoDB Atlas.
  2. It tests itself on practice questions with known answers.
  3. It learns from you. 👎 + "do this instead" changes your answers at once. If 2+ people ask for the same thing, it tries it for everyone.
  4. It keeps a change only if it's proven better on unseen questions with zero privacy leaks. Otherwise the change is undone.
  5. It can't unlock itself. Access rules, privacy masking and the audit log are locked. Big changes wait for a manager.
