How it works (30-second version)
  1. Every team and every agent has a "playbook": how many documents to read, rules to follow, what to refuse. Each version is saved in MongoDB Atlas.
  2. It tests itself. Practice questions with known answers give it a score. Wrong answers show what to fix.
  3. It learns from you. 👎 + "do this instead" applies to you right away. If two or more people ask for the same thing, the agent tries it for everyone.
  4. It keeps a change only if it's proven better on questions it has never seen, with zero privacy leaks. Otherwise the change is undone.
  5. It can never unlock itself. Access rules, privacy masking and the audit log are locked. Suspicious suggestions are set aside, and big changes wait for a manager.
